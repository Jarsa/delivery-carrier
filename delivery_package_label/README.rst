Choose, per delivery method, when the carrier labels of a delivery are
created when the carrier integration creates one label per package:

- **On validation**: the standard flow of Odoo.
- **On demand**: a *Create Carrier Labels* button on the delivery, once
  it is ready, creates the label of each package; validation creates the
  missing ones.
- **In background**: validation is immediate and a scheduled action
  creates the labels one package at a time, saving each one. For
  deliveries with dozens of packages, where creating every label while
  validating would exceed the time limit of the request.
- **When each package is packed**: *Put in Pack* creates the label of
  the new package and downloads one file with the package label of the
  operation type (when it prints on packing) followed by the carrier
  label, ready for the label printer.

Each label is saved on its package (tracking reference of
``delivery_package_tracking``) as soon as the carrier returns it: an
error on one package keeps the labels already created, and the button or
the next run only creates the missing ones.

Configuration
=============

1. Go to *Inventory > Configuration > Delivery Methods* and open a
   method whose integration creates labels per package, with
   *Integration Level* *Get Rate and Create Shipment*.
2. Choose *Carrier Labels*.
3. For *When each package is packed*, on the operation type (tab
   *Barcode App* or *Hardware*) enable *Print Package Label* and choose
   the same format as the carrier labels (ZPL or PDF) to get both labels
   in one file.

The *Tracking Reference per Package* of the delivery method is not
required for the modes other than *On validation*: the labels fill it
in.

Carrier integrations support this module by implementing
``<delivery_type>_send_package(picking, package)``, which creates the
label of one package and returns ``tracking_number``, ``exact_price``
and ``attachment_ids``.

Usage
=====

- *On demand*: open a ready delivery with packages and click *Create
  Carrier Labels*, then validate.
- *In background*: validate the delivery; the chatter shows when every
  label is created. If a label fails, the delivery shows the error, an
  activity is scheduled and *Create Carrier Labels* retries the missing
  labels.
- *When each package is packed*: pack the goods; each *Put in Pack*
  downloads the labels of the new package.
