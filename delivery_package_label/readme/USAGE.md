- *On demand*: open a ready delivery with packages and click *Create Carrier
  Labels*, then validate.
- *In background*: validate the delivery; the chatter shows when every label is
  created. If a label fails, the delivery shows the error, an activity is
  scheduled and *Create Carrier Labels* retries the missing labels.
- *When each package is packed*: pack the goods; each *Put in Pack* downloads
  the labels of the new package.
