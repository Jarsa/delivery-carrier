1. Connect the label printer to the IoT box (*IoT > Devices*).
2. *Settings > Technical > Reports*: assign the printer to *Package Carrier
   Labels* (labels printed when each package is packed) and to *Shipping
   Labels* (labels printed on demand and on validation).
3. On the operation type of the deliveries, tick *Auto Print Carrier Labels*
   to print the labels created on demand or on validation.
